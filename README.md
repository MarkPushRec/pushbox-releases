# Pushbox

Finished builds of Pushbox, Push Record's project-file sync app for the Mac. The source lives in a
private repository; this one only holds releases.

**Download:** [pushbox.lastline.dev](https://pushbox.lastline.dev), or the `Pushbox.dmg` on the
[latest release](https://github.com/MarkPushRec/pushbox-releases/releases/latest).

Signing in needs a Push Record Google account. Pushbox checks here for new versions and offers to
install them.
